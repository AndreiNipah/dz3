# Countries Trainer

Финальный проект по Android-разработке на базе приложения Countries Explorer.

Изначально приложение представляло собой справочник стран на основе REST Countries API: список стран, поиск, деталка, избранное и история просмотров. В финальной версии проект был расширен до offline-first mini-product для изучения столиц стран.

Приложение сохранило базовую функциональность справочника, но теперь содержит собственную локальную учебную систему: тест столиц, историю попыток, прогресс по странам, повтор ошибок, настройки и фоновое обновление кэша.

## Что добавлено в финальной работе

- Тест столиц `Capital Quiz`.
- Выбор области теста: World, Europe, Asia, Africa, Oceania, Americas, North America, South America, Eurasia.
- Выбор количества вопросов.
- Режим `Repeat mistakes` для повторения стран, где пользователь ошибался.
- Экран `Quiz Progress` со статистикой и историей попыток.
- Экран `Settings` с настройками теста и кэша.
- Offline-first кэш стран и деталей стран в Room.
- TTL для кэша.
- Фоновая синхронизация кэша через WorkManager.
- Unit-тесты на новую бизнес-логику.

## Новые пользовательские данные

В Room добавлены новые локальные сущности:

- `CachedCountryEntity` - кэш списка стран.
- `CachedCountryDetailsEntity` - кэш деталей страны.
- `QuizSessionEntity` - одна попытка прохождения теста.
- `QuizAnswerEntity` - ответ пользователя на конкретный вопрос.
- `CountryLearningProgressEntity` - прогресс пользователя по конкретной стране.
- `CacheMetadataEntity` - данные об актуальности кэша.

Пользовательские данные не хранятся формально: они влияют на поведение приложения. Например, ошибки пользователя используются для генерации режима `Repeat mistakes`.

## Реализованные сценарии

### 1. Прохождение теста столиц

Пользователь открывает `Capital Quiz`, выбирает область и количество вопросов, подготавливает тест, отвечает на вопросы и получает результат.

После завершения теста результат сохраняется в локальную базу.

### 2. Повтор ошибок

Если пользователь ошибается в тесте, ошибка сохраняется в `CountryLearningProgressEntity`.

После этого пользователь может выбрать режим `Repeat mistakes`, и приложение создаст новый тест только по странам, где ранее были ошибки.

### 3. Просмотр прогресса

На экране `Quiz Progress` пользователь видит:

- общее количество попыток;
- количество правильных и неправильных ответов;
- процент правильных ответов;
- список стран, где было больше всего ошибок;
- последние попытки прохождения теста.

### 4. Настройки приложения

На экране `Settings` пользователь может настроить:

- область теста по умолчанию;
- режим теста по умолчанию;
- количество вопросов по умолчанию;
- срок жизни кэша;
- обновление кэша только через Wi-Fi.

Настройки сохраняются через DataStore и применяются при следующем открытии теста.

## Offline-first часть

Список стран и детали стран сохраняются в Room.

После первичной загрузки приложение может использовать локальные данные без сети:

- список стран берётся из локального кэша;
- поиск работает по сохранённым странам;
- тесты генерируются из локального кэша;
- избранное, история просмотров, история тестов и прогресс пользователя хранятся локально.

Сеть используется для обновления данных, а не как единственный источник состояния экрана.

Если API или интернет недоступны, приложение пытается использовать уже сохранённые данные из Room.

## Фоновая обработка

Для фонового обновления используется WorkManager.

Фоновая задача `CountriesSyncWorker` вызывает `SyncRepository`, который проверяет:

- когда кэш обновлялся последний раз;
- истёк ли TTL кэша;
- включена ли настройка обновления только через Wi-Fi;
- доступна ли подходящая сеть.

Если кэш устарел, выполняется обновление стран из API и сохранение результата в Room.

## DataStore

DataStore используется только для настроек приложения:

- область теста по умолчанию;
- режим теста по умолчанию;
- количество вопросов по умолчанию;
- TTL кэша;
- обновление только через Wi-Fi.

Пользовательские данные уровня истории, прогресса и ответов хранятся в Room.

## Тесты

В проект добавлены unit-тесты на новую ключевую функциональность.

### `QuizAreaMapperTest`

Проверяет локальную классификацию стран по областям теста.

### `QuizQuestionGeneratorTest`

Проверяет генерацию вопросов:

- вопрос содержит 4 варианта;
- правильный ответ есть среди вариантов;
- варианты не повторяются;
- страны фильтруются по выбранной области;
- при недостаточном количестве стран тест не создаётся.

### `QuizRepositoryMistakesTest`

Проверяет режим `Repeat mistakes`: вопросы создаются только по странам, где пользователь ранее ошибался.

### `SyncRepositoryTest`

Проверяет offline/sync-логику:

- свежий кэш не обновляется повторно;
- устаревший кэш обновляется;
- при включённой настройке Wi-Fi-only синхронизация пропускается без Wi-Fi.
