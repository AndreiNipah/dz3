10. Добавлен тест нетривиального асинхронного поведения

Добавлен тест для поиска, который проверяет отмену устаревшего запроса.


Это проверяет, что устаревший результат поиска не попадает в UI.

13. Добавлен MainDispatcherRule

Для тестирования ViewModel был добавлен `MainDispatcherRule`.

Он нужен, чтобы в unit-тестах заменить `Dispatchers.Main` на тестовый dispatcher.

Это позволяет стабильно тестировать корутины, которые запускаются через `viewModelScope`.

14. Тесты сделаны детерминированными

Для тестов корутин используются:

* `runTest`;
* `advanceTimeBy`;
* `advanceUntilIdle`;
* тестовый dispatcher.

Это позволяет контролировать debounce, задержки и выполнение корутин без реального ожидания времени.
